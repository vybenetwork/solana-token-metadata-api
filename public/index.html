VybeToken stats

Metadata, holders, traders, and trades

Enter a mint and this page loads its name, symbol, market cap, and 24-hour volume, plus top holders and top traders. Price and supply sit on that same token response, along with the logo when present.

Trade rows for the mint load with program labels. Holder share and 30-day trader PnL load next to those trades for the same mint you entered. A free API key on Vybe is enough to start. Paid plans raise the rate limit.

Generate a free API key to get started

Endpoints Used:

  • Token Details API GET /v4/tokens/{mintAddress}
  • Token Trade History API GET /v4/trades
  • Top Token Holders API GET /v4/tokens/{mintAddress}/top-holders
  • Labeled Programs API GET /v4/programs/labeled-program-accounts
  • Top Token Traders API GET /v4/wallets/top-traders

  • Token details

    Name, symbol, market cap, and 24-hour volume for the mint.

  • Top holders

    Largest holders and the share of supply each one holds.

  • Top traders

    Wallets ranked by 30-day realized PnL on that mint.

  • Trades

    Recent trades for the mint, with program addresses labeled.

Also answered here

What loads for one mint?

Token details, top holders, 30-day top traders, and recent trades.

How do I get a Vybe API key?

Generate a free API key on Vybe. A free key starts your first calls. Paid plans raise the rate limit.

What do the holder rows show?

Each holder's share of supply, sorted by the percentage held.
